= IALA reference layouts — which PDF applies to which document type

Mapping for the IALA XSLT work (mn-native-pdf#1109). The reference PDFs
are the IALA publications, publicly downloadable from
https://www.iala.int[www.iala.int]; local copies are organized in
`reference-docs/<doctype>/` of mn-samples-iala for convenience.
Transcribing them into Metanorma format is this repository's purpose.

[cols="1,3,2"]
|===
|Doctype |Reference documents (local `reference-docs/<dir>/`) |Cover-family layout drivers

|standard (S)
|S1040 Ed2.0, S1050 Ed2.0, S1060 Ed2.0
|"THE GENERAL ASSEMBLY" recital page; 8 fixed sections; cover + footer MRN

|recommendation (R)
|R1023, R1024, R1025, R1026, R1027 Ed1.1
|optional "(INFORMATIVE)" cover qualifier; "THE COUNCIL" recitals (first RECALLING mandatory); Document History table

|guideline (G)
|G1195, **G1199 Ed1.0 (docx + pdf — newest template)**, G1201, Style Guide G1115
|Contents page; free main body; Document Revision table; back matter (Definitions boilerplate, Abbreviations, References)

|model-course (C)
|C0103-1 Ed3.0, C2007-1 Ed3.0
|course/module layout (L1/L2 levels)

|resolution (P/GA)
|GA01-Res.01/.02/.12, A12-01, A13-01
|resolution statements; GA series + legacy A series

|manual / plan
|MARCOM manual, MRCP Ed3 (2017)
|older layout family, low priority

|report (X)
|Cyber-security workshop report
|report cover

|all
|Style Guide G1115 + logo guide (`brand/`)
|Calibri; headings/table text #00558C; covers color-coded per type (palette in G1115 appendix 3); footer replicates cover fields incl. MRN
|===

G1199's working Metanorma transcription: `sources/g1199/` on branch
`initial-import` — compiles via the iala taste to semantic + presentation
XML (the XSLT input).
